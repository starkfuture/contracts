# docuseal-stark

Stark Future's DocuSeal: upstream [DocuSeal](https://github.com/docusealco/docuseal) Community
edition (AGPL-3.0) plus roles, so people see only their own contracts and the templates they are
allowed to use. See [FORK.md](FORK.md) for what changes, why, how to test and how to upgrade.

Source for every running version: this repository (`patches/`, `overlay/`, `tools/`, `Dockerfile`)
together with the upstream tag named in `UPSTREAM`.
